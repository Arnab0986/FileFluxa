# UI / UX REFERENCE AUDIT

## Inspected Design Patterns & Aesthetics
- **Color Palette**: Deep Midnight Navy (#030712, #0B0F19), Graphite (#111827), Electric Cyan (#22D3EE), Restrained Violet (#A855F7), Emerald Green (#10B981).
- **Typography**: Inter / System Sans-Serif font stack with clear scale hierarchy and crisp contrast.
- **Layout Architecture**: Dashboard shell featuring collapsible sidebar navigation, top header with instant global tool search, and responsive workspace layout.
- **Animations**: Powered by Framer Motion. Smooth page transitions, micro-interactions, drag-and-drop highlight feedback, and queue item state transitions. Respects `prefers-reduced-motion`.
- **Accessibility**: High color contrast (WCAG 2.2 AA compliant focus states), semantic HTML tags, keyboard navigation support.
