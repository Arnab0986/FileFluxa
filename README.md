# FileFluxa

Every file. Every format. One powerful workspace.

FileFluxa is an all-in-one, privacy-first file-processing workspace running entirely in your browser with **₹0 recurring infrastructure cost**.

## Features
- **Image Studio**: Convert, compress, and resize images locally via HTML5 Canvas.
- **PDF Lab**: Merge and split PDF documents securely using `pdf-lib`.
- **Document Converter**: Robust CSV-to-JSON and JSON-to-CSV data transformations.
- **Audio Lab**: Decode, trim, and adjust audio using the Web Audio API.
- **Archive Tools**: Create and compress ZIP archives client-side with `JSZip`.

## Development Setup
```bash
npm install
npm run dev
```

## Production Build
